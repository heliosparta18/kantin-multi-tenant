# Kantin Multi-Tenant

Aplikasi manajemen kantin berbasis multi-tenant yang dibangun menggunakan Laravel.

## Requirements (Syarat Alat)
- PHP (versi terbaru sesuai environment kamu)
- Composer
- Node.js & NPM
- MySQL / Database server

## Cara Setup
1. Clone repository ini atau buka foldernya.
2. Salin file `.env.example` menjadi `.env`:
   ```bash
   cp .env.example .env
